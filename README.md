# Kontely website v2

Nästan lanseringsklar statisk webbprototyp för Kontely.

## Sidor
- `index.html` – huvudlandningssida
- `produkt.html` – produktfördjupning
- `byra.html` – sida för redovisningsbyråer
- `kontakt.html` – demo/intresseformulär (frontend-demo)
- `integritet.html` – tydlig juridisk placeholder
- `villkor.html` – tydlig juridisk placeholder

## Assets
- `styles.css`
- `app.js`
- `logo.svg`
- `favicon.svg`

## Innan skarp lansering
1. Kontrollera varumärket Kontely och domäner hos relevanta register.
2. Koppla formuläret till e-post/CRM/backend.
3. Lägg in verkliga kontaktuppgifter och juridiskt bolag.
4. Färdigställ GDPR, DPA, cookiehantering, säkerhetsdokumentation och användarvillkor.
5. Verifiera exakt vilka åtgärder produkten kan utföra i Fortnox och anpassa copy efter verklig funktionalitet.
6. Lägg till analytics först när cookie- och integritetsupplägg är klart.

## Lokalt
Öppna `index.html` i webbläsaren eller kör via valfri statisk webbserver.
